# ✈️ NMFlights — Full Stack MERN Flight Platform

🚀 **NMFlights** is a full-stack MERN application that simulates a modern flight exploration platform.  
It demonstrates real-world full-stack engineering including API development, database integration, map visualization, and cloud deployment.

> Built as a practical project to strengthen real-world MERN development skills.

## 🧠 Project Overview

NMFlights allows users to:

- Explore flight routes
- View locations using interactive maps
- Communicate with backend APIs
- Experience a modern SPA (Single Page Application)

This project focuses on clean architecture, scalable structure, and deployment workflows used in production environments.

---

## 🏗️ Tech Stack

### Frontend
- ⚛️ React (Vite)
- 🔁 React Router
- 🌍 Axios
- 🗺️ Leaflet & React-Leaflet
- 🎬 Lottie Animations
- 🎨 CSS

### Backend
- 🟢 Node.js
- 🚂 Express.js
- 🍃 MongoDB
- 📦 Mongoose
- 📧 Nodemailer
- 🔐 dotenv + CORS

### Deployment
- ▲ Vercel (Frontend)
- 🚀 Render (Backend)
- ☁️ MongoDB Atlas (Database)

---

## ⚙️ System Architecture
React Frontend (Vercel)
↓ API Calls
Express Backend (Render)
↓
MongoDB Atlas (Cloud Database)

- ✈️ Flight exploration UI
